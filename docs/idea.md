# Твоя Бухта - Вебсайт - 13.11.2026

Сайт разрабатывается для проекта "Верю в Чудо", конкретно - пространства "Твоя Бухта".
Контакты:

- [[вк](https://vk.com/your_buhta39)]
- [[тг](t.me/tvoyabukhta)]

Имеется отдельный сайт организации "Верю в Чудо": [[Тык](https://www.deti39.com/)]

## Возможности

Данный сайт должен иметь информационный функционал тг-канала:

1. Расписание рабочих дней и график работы.
2. Общая информация об организации.
3. Информация о координаторах.
4. Анонс индивидуальных мероприятий.

Также необходимо реализовать функционал записи к психологу, записи на мероприятия и общий чат.

Чат можно интегрировать через имеющийся тг

Запись к психологу в данный момент реализуется через Яндекс.Формы.

Необходимо сделать вкладку-навигатор(?) с информацией о том, где найти офис.
